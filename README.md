A newspaper front page that sums up the world's news of **Monday 23 November 2026** in one image: 51 date-checked stories — the Ukrainian sea-drone strike that sank a Russian warship off Benghazi, the COP31 climate summit ending without a deal, Jensen Huang's return to Nvidia, Russian strikes around Kyiv, and a timeline, markets strip and in-brief column covering the rest of the day.

`main.ts` (Node 22, standard library only) copies the bundled `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
